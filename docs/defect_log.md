A Defect Log is a document used to record errors or bugs found during software testing.
Whenever you discover a bug, record its details in the Defect Log.
Sample Defect Log
Bug ID	Description	Severity	Priority	Status
B01	Booking not saving	High	High	Open
B02	Wrong equipment availability	High	High	Open
B03	Cancel button not working	Medium	Medium	Fixed
B04	Missing validation message	Low	Low	Fixed
B05	Duplicate booking allowed	High	High	Open

Important Terms
•	Severity: How serious is the bug?
•	Priority: How urgently should the bug be fixed?
•	Open: The bug has not been fixed yet.
•	Fixed: The developer has corrected the bug.
•	Closed: Testing confirms that the bug has been successfully fixed.
