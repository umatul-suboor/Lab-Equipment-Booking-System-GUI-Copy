Prepare the Test Plan  :
A Test Plan is a document that defines how different features of the Lab Equipment Booking System will be tested.
Project Objective
The Lab Equipment Booking System provides students and teachers with the ability to book laboratory equipment, manage bookings, and check equipment availability.
Testing Scope
The following features will be tested:
•	User Registration and Login
•	View Equipment
•	Check Equipment Availability
•	Book Equipment
•	Cancel Booking
•	Return Equipment
•	Admin Manage Equipment

A. Test Cases
These test cases can be included in your Test Plan.
Test ID	Test Scenario	Expected Result
TC01	Register with valid details	Account created successfully
TC02	Login with correct credentials	Login successful
TC03	Login with wrong password	Error message displayed
TC04	View equipment list	Equipment displayed
TC05	Book available equipment	Booking successful
TC06	Book unavailable equipment	Booking rejected
TC07	Cancel existing booking	Booking cancelled
TC08	Return booked equipment	Equipment marked as available
TC09	Admin adds equipment	Equipment added successfully
TC10	Submit empty booking fields	Validation message displayed

B. Test Case Result Sheet
This sheet records the actual results after executing the test cases.
